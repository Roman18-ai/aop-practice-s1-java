# Практична робота 8 — Питання для обговорення

### 1. Як знайти найбільше число в масиві?
Створити змінну max, присвоїти їй перший елемент масиву та пройти циклом по інших елементах. Якщо знайдене число більше за max, оновити його.

### 2. Чому майже кожна задача з масивами починається з одного проходу циклом?
Цикл дозволяє послідовно перевірити всі елементи масиву та виконати потрібні обчислення.

### 3. Що робити, якщо масив порожній?
Потрібно перевірити довжину масиву перед обробкою та передбачити відповідь, наприклад 0, null або повідомлення про помилку.

### 4. Як знайти найкращий день купівлі та продажу акцій за один прохід?
Зберігати мінімальну ціну, яку зустріли, та максимальний можливий прибуток. Для кожного наступного дня обчислювати різницю між поточною ціною та мінімальною.

### 5. Як миттєво відповідати на тисячу запитів про суму чисел від 10 до 1000?
Використати формулу арифметичної прогресії: S = (a + b) * n / 2. Результат обчислити один раз і використовувати для всіх запитів.

### 6. Чи корисно вивчати поширені алгоритмічні шаблони?
Так, вони допомагають швидше розв'язувати задачі та знаходити ефективні рішення. Але важливо розуміти принцип їхньої роботи, а не просто копіювати готовий код.
